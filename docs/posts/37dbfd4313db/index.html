折半搜索

对于一个排序好的线性表：

  • 折半搜索时, 先求位于搜索区间正中的对象的下标mid，用其关键码与给定值x比较:
    • Element[mid].key == x，搜索成功；
    • Element[mid].key > x，把搜索区间缩小，到表的前半部分，继续折半搜索；
    • Element[mid].key < x，把搜索区间缩小，到表的后半部分，继续折半搜索。

折半搜索的判定树： 注意叶节点也要画出来，表示没有成功找到。

Binary Search Tree

BST实际上就是线性表折半搜索的判定树。 二叉搜索树是一种二叉树的树形数据结构，其定义如下：

  1. 空树是二叉搜索树。
  2. 若二叉搜索树的左子树不为空，则其左子树上所有点的附加权值均小于其根节点的值。
  3. 若二叉搜索树的右子树不为空，则其右子树上所有点的附加权值均大于其根节点的值。
  4. 二叉搜索树的左右子树均为二叉搜索树。

BST删除

删除之后为了保持BST的性质，需要满足：

  • 如果被删除节点left为nullptr，则用right来替代
  • 如果被删除节点right为nullptr，则用left来替代
  • 否则，用lefMost(right)或者rightMost(left)来替代

AVL树

AVL的核心是如何维护平衡，容易想到，破坏平衡的操作有插入和删除，因此，在插入和删除操作中需要维护树的平衡。 定义：平衡因子=height(root->right)-height(root->left) 存在如下四种情况：

  • LL
  • LR
  • RL
  • RR

AVL树的高度

设 Nh 是高度为 h 的AVL树的最小结点数。根的一棵子树的高度为h-1，另一棵子树的高度为h-2，这两棵子树也是高度平衡的。因此有 N0 = 0 (空树) N1 = 1 (仅有根结点) Nh = Nh-1 + Nh-2 +1 , h > 1 注意是类符合斐波那契数列数列。 因此，AVL树的插入删除操作的复杂度都是O(logn)
