如何找到所有的匹配情况？

在找到一个完整的匹配的时候，如何紧接着找下一个匹配呢？

T: abcabcabc
P: abcabc
容易得到P的next数组为 -1 0 0 0 1 2
在匹配的过程中，会出现：

当匹配到c的时候，发现T[i]==P[j]，因此i++;j++;之后，满足条件j==lenP,成功匹配一次，进行下一次匹配，此时最佳的选择是重新给j复制为next[j]，让P串回溯，进行下一次匹配的查找，因为next[j]的含义即为前整个串的最长公共前后缀长度，回到next[lenP]这个位置能够最大程度地减少匹配的成本。
