树的概念

二叉树

二叉搜索树是一种特殊的二叉树，满足以下性质：

  1. 空树是二叉搜索树。
  2. 若左子树非空，则其中所有节点的权值均小于根节点的权值。
  3. 若右子树非空，则其中所有节点的权值均大于根节点的权值。
  4. 左右子树本身也都是二叉搜索树。

在二叉搜索树上执行基本操作（如查找、插入、删除）的时间复杂度与树的高度成正比。对于包含 nnn 个节点的二叉搜索树：

  • 最优时间复杂度为 O(log⁡n)O(\log n)O(logn)，出现在树结构平衡时；
  • 最坏情况为 O(n)O(n)O(n)，发生在树退化为链表时；
  • 随机构建的二叉搜索树，其期望高度为 O(log⁡n)O(\log n)O(logn)。

重要性质：

  1. 若根节点位于第 1 层，则第 kkk 层最多有 2k−12^{k-1}2k−1 个节点。
  2. 设度为 iii 的节点数为 nin_ini​，则有 n0=n2+1n_0 = n_2 + 1n0​=n2​+1。

    • 因此，叶节点数量由度为 2 的节点决定。
    • 向树中添加一个新节点（度为 0）时：

      • 若接在度为 1 的节点后，则叶节点数和度为 2 的节点数各增加 1。

二叉树的遍历

二叉树的遍历是指按照一定的顺序访问树中的每个结点，且每个结点仅被访问一次。 设：

  • 访问根结点记为 VVV；
  • 遍历左子树记为 LLL；
  • 遍历右子树记为 RRR。 根据 VVV 在访问序列中的相对位置，可定义三种基本遍历方式：
  • 前序遍历（preorder）：VLRVLRVLR，对应镜像形式为 VRLVRLVRL
  • 中序遍历（inorder）：LVRLVRLVR，对应镜像形式为 RVLRVLRVL
  • 后序遍历（postorder）：LRVLRVLRV，对应镜像形式为 RLV其中，RLV 其中，RLV其中，V$ 的位置决定了遍历类型。 递归实现较为简单，但在某些场景下（如需要显式控制遍历顺序或避免递归栈溢出），可使用**栈（stack）**来模拟递归过程。以下给出三种遍历的非递归实现伪代码：

前序遍历（preorder）

  • 访问顺序为“根 → 左 → 右”；
  • 每次访问当前节点后，先将右子节点压入栈（因为右子树应后访问），再向左子树移动；s
  • 若当前节点为空，则从栈中弹出一个节点继续

中序遍历（inorder） 逻辑：

  • 访问顺序为“左 → 根 → 右”；
  • 每次不断向左下探，将所有左节点依次压栈；
  • 当无法再向左时，弹出栈顶节点并访问它，然后转向其右子树。

后序遍历（postorder）
后序遍历使用栈模拟时，需要额外维护一个指针（lastVisited）来记录上一个访问过的节点，以判断右子树是否已被访问：

  • 尽可能向左下探，将节点依次压栈；
  • 当无法继续向左时，观察栈顶节点的右子树：
    • 若右子树存在且未访问，则转向右子树；
    • 否则访问当前节点并弹栈。

线索化后：是否还有空指针域的数量是多少？有的话有多少个？分别是谁？ 对于任何一个线索化的树（不管线索化的方法），得到的遍历顺序假设为ABCDEFG，那么中间的BCDEF一定要么有左右子树，要么有前驱和后继，只有第一个遍历的节点和最后一个遍历的节点有可能出现空指针域。

  • 对于中序线索化：第一个遍历的节点是最左下的节点，其左指针可能为空（因为没有前驱）；最后一个遍历的节点是最右下的节点，其又指针可能为空（因为没有后继）
  • 对于前序线索化：第一个遍历的节点是根节点，右指针要么是后继节点，要么是右子树，因此不存在为空的可能。左指针在左子树为空的时候，为空（因为没有前驱节点）；最后一个遍历的节点是最右下的节点，不存在右指针（因为没有后继）
  • 对于后续线索化： 第一个遍历的节点是最左下的节点，其没有前驱节点，因此左指针可能为空。最后一个遍历的节点是root，没有后继节点，因此当右子树不存在的时候，其右指针为空。 Conclusion：中序为2个，前序和后续线索化为1个或者2个。

森林转二叉树

  • 将一般树化为二叉树表示就是用树的子女-兄弟表示来存储树的结构
  • 做法：
    • 若 F 为空，即 n = 0，则对应的二叉树 B 为空树。
    • 若 F 不空，则
      • 二叉树 B 的根是 F 第一棵树 T1 的根；
      • 其左子树为B (T11, T12, …, T1m)，其中，T11, T12, …, T1m 是 T1 的根的子树；
      • 其右子树为 B (T2, T3, …, Tn)，其中，T2, T3, …, Tn 是除 T1 外其它树构成的森林。

森林的遍历

深度优先

  • 森林的先根遍历即为二叉树的先序遍历
  • 森林的后根遍历即为二叉树的中序遍历

广度优先

  • 使用队列进行实现，每一次把当前层所有的元素入队；出队时，visit当前元素，之后把其subTrees入队

堆 Heap

注：下面讲的都是二叉堆

Heap即为priority_queue优先级队列，每一次出队的都是优先级最高的元素。在优先级队列中，某节点和其siblings没有一定的大小限制关系，但是任何一个节点都和其child，parent存在大小关系。 按照大小关系可以分为最小堆（越小的优先级越大）和最大堆 堆是一个完全二叉树，

堆的下标关系

  • 由于堆存储在下标从 0 开始计数的一维数组中，因此在堆中给定下标为 i 的结点时
  • 如果 i = 0，结点 i 是根结点，无双亲；否则结点 i 的父结点为结点 (i-1)/2；
  • 如果 2i+1＞n-1，则结点 i 无左子女；否则结点 i 的左子女为结点 2i+1；
  • 如果 2i+2＞n-1，则结点 i 无右子女；否则结点 i 的右子女为结点 2i+2。

堆的删除操作

错误的删除操作：删除节点A之后，把A的较小子树上移。（会破坏完全二叉树的性质） 正确的删除操作：将堆中的最后一个节点放在被删除的节点，之后进行siftDown.

堆的建立

堆的建立有两种方案，可以n次插入，或者先构建数组，再从最后一个非叶节点开始向下调整，逐步向前。 n次插入 考虑最后一排节点（节点数量级为n/2），每一个节点的时间开销为logn，因此结果为nlogn。 调整算法

  1. 从下到上，依次向下调整 从最后一个非叶节点开始，需要逐步调整n/2次（数量级是这个），每一次调整都是从当前调整的位置，一直到最后一个节点。 因为是往下调整的，深度越大，调整到次数越少。在最后一层不需要调整，倒数第二层最多只需要调整一次… （倒数第k层，至多需要调整k次）

S=n2∗0+n22∗1+n23∗2+...S= \frac{n}{2}*0+\frac{n}{2^{2}}*1+\frac{n}{2^3}*2+... S=2n​∗0+22n​∗1+23n​∗2+...

树的高度为log2nlog_2{n}log2​n ，调整次数可以由错位相减法得到，可以得到最终的时间复杂度为O(n)O(n)O(n) 2. 从上到下，依次向上调整 仅考虑最后一排的调整，也需要nlogn的复杂度，因此这样的复杂度和直接n次插入是一样的。

Huffman树

huffman tree

Huffman树是使得带权路径和最小的树。 Huffman树的构造算法

  1. 给定 n 个权值 {w0, w1, w2, …, wn-1}，构造 具有 n 棵扩充二叉树的森林 F = { T0, T1, T2,…, Tn-1 }，其中每棵扩充二叉树 Ti 只有一个带权值 wi 的根结点, 其左、右子树均为空。
  2. 重复以下步骤, 直到 F 中仅剩一棵树为止：
  3. 在 F 中选取两棵根结点的权值最小的扩充二叉树, 做为左、右子树构造一棵新的二叉树。置新的二叉树的根结点的权值为其左、右子树上根结点的权值之和。
  4. 在 F 中删去这两棵二叉树。
  5. 把新的二叉树加入 F。

可以使用Heap来存储权值，每一次从heap中删除两次，logn的复杂度，再插入一个也是logn的复杂度。 （如果使用数组+快速排序的方法，时间复杂度为n）
