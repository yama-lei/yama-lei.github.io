脚本解释 open函数打开"/flag"文件，然后文件描述符fd存在了rax寄存器中。

  • open函数参数：文件地址 read函数从文件描述符中读取最多128个字节存在栈顶rsp，返回值在eax中（表示的是读取的长度）

Exp3实验三

flag为flag{https://www.bilibili.com/video/BV1TM4y157UF?n=15aae955 } 脚本

利用数组越界读写实现GOT劫持四步操作：

  • 第一步：计算偏移。notes数组在bss段，puts@got在got.plt段，两者相距固定。(e.got['puts'] - e.symbols['notes']) 算出数组下标的offset（之后使用数组越界来访问puts数组的地址），用读功能泄露puts运行时地址
  • 第二步：计算libc基址。puts运行时地址减去libc文件中puts的偏移量：leaked_puts_addr - libc.symbols['puts']，得到libc加载基址
  • 第三步：计算system地址。基址加上system在libc中的偏移：libc_base + libc.symbols['system']，得到system真实地址
  • 第四步：劫持与触发。用写功能将puts@got覆写为system地址，再调用菜单的Secret功能执行puts(\sh")，实际变成system(\sh")拿shell

即：根据偏移量来获取到地址，然后执行sh程序获得shell
