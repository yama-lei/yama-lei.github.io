等价类和并查集

等价类

回顾离散数学的知识： 等价关系：
设 RRR 是非空集合 AAA 上的关系。若 RRR 同时满足自反性、对称性和传递性，则称 RRR 为 AAA 上的等价关系。若 ⟨x,y⟩∈R\langle x, y \rangle \in R⟨x,y⟩∈R（或记作 xRyxRyxRy），则称 xxx 等价于 yyy，记作 x∼yx \sim yx∼y。

等价类：
设 RRR 是非空集合 AAA 上的等价关系，对任意 x∈Ax \in Ax∈A，定义

[x]R={y∣y∈A∧xRy}[x]_R = \{ y \mid y \in A \land xRy \} [x]R​={y∣y∈A∧xRy}

称 [x]R[x]_R[x]R​ 为 xxx 关于 RRR 的等价类，简记为 [x][x][x]。

即，等价类中的任意一个元素均可代表该等价类。

Disjoint Set Union（DSU）

逻辑结构是森林，物理结果是数组。 书上写的我个人觉得讲得不清不楚，建议看这个并查集 - OI Wiki

书本实现 使用parent指针表示法，合并的时候将其中一棵树的parent指针改为另外一棵树，并且更新节点信息（比如更新节点计数等等） 在最差的情况下，退化成为链表（思考一下什么情况），优化方法：

  1. 父指针压缩（while idx has parent, idx->parent=idx->parent->parent)让树的高度为1
  2. 合并时进行比较，将节点数少的移到节点数多的数上

习题：P3367 【模板】并查集 - 洛谷 P1525 [NOIP 2010 提高组] 关押罪犯 - 洛谷

并查集技巧：

  • 在findParent的时候剪短树的高度
  • 在用并查集将集合分成两部分时，为表示a和b不在同一个集合，可以把a和b+N，b和a+N进行unite操作（敌人的敌人是朋友，如果a和b不在一个集合，a和c不在一个集合，那么b和c应该在同一个集合，实际上因为unite(b,a+N)和unite(c,a+N)所以b和c的确在同一个集合。

Hash Table

散列表通过散列函数将键值映射为下标，然后将数据存储在数组中对应下标的位置。当按照键值查找元素的时候，用同样的散列函数将键值转化为数组下标，从对应的数组下标的位置取出数据。

即把一个很大的空间，映射到一个相对小的空间，然后把key存储在hash(key)的位置，之后查询key对应的value的时候，也是先计算hash(Key)之后，把对应位置的值取出。

散列函数

构造散列函数时的几点要求：

  • 散列函数应是简单的，能在较短的时间内 计算出结果。
  • 散列函数的定义域必须包括需要存储的全部关键码，如果散列表允许有 m 个地址时，其值域必须在 0 到 m-1 之间。
  • 散列函数计算出来的地址应能均匀分布在整个地址空间中 : 若 key 是从关键码集合中随机抽取的一个关键码, 散列函数应能以同等概率取0 到 m-1 中的每一个值。

哈希冲突

拉链法 也称开散列法（open hashing）。 拉链法是在每个存放数据的地方开一个链表，如果有多个键值索引到同一个地方，只用把他们都放到那个位置的链表里就行了。查询的时候需要把对应位置的链表整个扫一遍，对其中的每个数据比较其键值与查询的键值是否一致。如果索引的范围是 1…𝑀，哈希表的大小为 𝑁，那么一次插入/查询需要进行期望 𝑂(𝑁𝑀) 次比较。

闭散列法 闭散列方法把所有记录直接存储在散列表中，如果发生冲突则根据某种方式继续进行探查。 比如线性探查法：如果在 d 处发生冲突，就依次检查 d + 1，d + 2……

下面主要介绍线性探测法：

  • 对于查找：正常计算hash(k)，如果arr[hash(k)]!=k，那么查找下一个(hash(k)+1)直到arr[hash(k)+i]==0 || arr[hash(k)+i]=k前者说明k不存在，后者说明k存储在hash(k)+i的位置
  • 对于插入：计算hash(k)，如果arr[hash(k)]!=0说明被占用，尝试寻找下一个位置，直到hash(k)+i对应的位置为0（说明没被占用）

注意：上课的时候侧重将了线性探测法，尤其是ASL的计算（Average Search Length）
