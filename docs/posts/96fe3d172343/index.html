中缀转后缀

考虑一个中缀表达式： A + B*C -D，最终会变成：A B C *+D-

我们发现：

  • 操作数的相对顺序不变
  • 在运算顺序的限定下，存在FILO的现象 因此，可以这样操作： 读到operand的时候，直接输出；读到opertor的时候，存入栈中；读到“（”直接skip，读到“）”的时候弹出栈一个operator ((A+B)-(C * D)) A B + C D * - 但是，这种解法需要我们先把括号给补齐，那么有没有一种算法，可以自由地处理各种形式的表达式呢？

我们可以选取这样的方法，将中缀表达式直接转换为后缀表达式：

  1. 若为‘（’，入栈
  2. 若为‘）’，则依次将栈中的运算符加入后缀表达式，直到出现‘（’，并从栈中删除‘（’
  3. 若为‘+’，‘-’，‘*’，‘/’
  • 栈空，入栈
  • 栈顶元素为‘（’,入栈
  • 高于栈顶元素优先级，入栈
  • 否则，依次弹出栈顶运算符，直到一个优先级比它低的运算符或‘（’为止 简单来说：
  • 如果是左括号，那么入栈，如果是右括号就一直出栈，直到左括号出栈
  • 如果是操作符：
    • 如果当前的优先级比栈顶的优先级高，那么入栈
    • 否则出栈，直到遇见优先级更低的运算符或或者”（“

卡特兰数

问题 若入栈的顺序为1,2,3,4的话，输出所有可能的出栈的序列？ 思路 使用回溯的思路：使用out，in数组分别代表出栈和准备入栈的数组

  1. 如果out已经有n个数字了，直接输出
  2. 否则，说明在栈里和in数组里面有数字，依次执行下面这两条
    1. 如果栈不为空，那么在这这里采取回溯的思路：
      • 尝试pop一个数字并且存入out中
      • 递归调用函数
      • 把之前的数字push回栈中（回溯）
    2. 如果in数组不为空，那么在这里使用回溯的思路：
      • 尝试将一个数字push进栈中
      • 递归调用函数
      • 把数字pop出栈，存回in数组（回溯） 如果要求计数呢？ 如果只是计数的话，可以直接参考这个文章卡特兰数 - OI Wiki，使用递推公式来解决，不过需要注意，最好使用动态规划把之前算过的结构保存起来，减少复杂度。

怎么理解catalan数？

  1. 考虑第一个元素（1）的出栈可能位次，把第一个元素所有的出栈可能加起来即可得到递推公式
  2. 本质是出栈的次数不能超过当前入栈的次数。

合法的出栈序列？

  1. 看出栈序列的最后一项，如果最后一项是a，那么前a-1项都小于a 。而且前a-1项也是合法序列。剩余的第a项到n-1项也是合法序列。比如序列435612是非法序列。
