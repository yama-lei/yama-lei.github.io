靶机五

发表于2025-10-28|更新于2025-11-04|NJUCS网络攻防实战
|总字数:970|阅读时长:3分钟|浏览量:

发现存在22 80和8000的服务，分别对齐进行扫描 在8000端口存在http-server 显示unsuported-method，尝试用burpsuite抓包改为post请求之后，还是没出现错误

在80端口存在页面，发现有一个搜索栏，子啊搜索栏中使用输入'没想到直接出现了错误

尝试使用burpsuite对搜索进行拦截，然后把http请求保存在sqlinject文件中，然后使用sqlmap进行检查

–dbs 来看有哪些数据库 -D dbname --tables 来看dbname这个数据库有哪些tables -T 查看某一个table，用-C来查看哪一列，等等。

全部都可以用sqlmap自带的字典，来把admin的email和passwd来down下来

使用dirsearch进行扫描： 可以直接下载数据库。 然后登录admin的用户即可，然后profile上传一句话木马 admin的用户听人说是admin admin@localhost.com? （实际上根本是不需要的，因为普通用户也是可以上传profile的，效果是完全一样的）

尝试使用蚁剑（基于中国菜刀）

把一句话木马上传即可。

然后建立一句话脚本，然后建立webshell，接着直接找21年的一个漏洞，进行提权。 （可以先把webshell用nc再建立一个shell，再使用python命令构建一个“真的”shell，重复之前的操作。 （可以用这个仓库的解决方案lukechilds/reverse-shell: Reverse Shell as a Service）

查看etc/passwd/目录。发现我们可以进入socnet用户的home目录。 这个用户的目录下有一个monitor.py文件， add_record有s位，可以尝试提权 peda目录是用于反汇编的。

最简单的方案： 使用lsb -release -b 发现版本为： 可以利用CVE-2021-3493的漏洞（最好不要直接使用antSword，而是利用其建立一个reverse shell再做）当时

靶机作者的思路： 在monitor.py入手 发现想要指向我的cmd，需要输入passcode，才能够执行。passcode的内容为debuggging_pass=random.ranint(1000,9999)因此，尝试用穷举法进行尝试！

monitor是一个server，因此，考虑写一个client来处理（参考https://docs.python.org/zh-cn/3/library/xmlrpc.html） 比如写一个client.py程序，来运行，直到穷举出passcode

checksec来进行安全分析

  • 先apt install checksec
  • 然后用httpserver把文件传输过去
  • 然后检查漏洞发现 检查checksec应用发现存在漏洞，使用gdb进行调试（加入peda插件）发现，在询问是否遇见问题的时候，输出0，让explain的时候输入100个A，出现调试信息.

（在调试的时候info function）程序里面有一个vuln和backdooe函数，检查vuln函数的反汇编代码（disas vuln)，发现调用了strcpy

因此：我们需要想办法执行backdoor来执行这个

我的过程： 获得shell之后，把文件socnet的home目录copy到tmp下，并且把checksec也copy到tmp下

建立reverseshell： 把这个shell文件上传到靶机
