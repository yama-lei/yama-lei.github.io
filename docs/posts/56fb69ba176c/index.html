提权方式

使用uname -a 来获取版本信息。发现是linux内核是3.13版本，使用search spolit来获取到版本漏洞。发现可以使用37292这个漏洞，查看代码内容，里面有写怎么编译运行获取权限。

[!?] 课上提问：如果靶机上没有gcc环境呢？ 我的想法：如果靶机上没有gcc环境，那么可能需要自己在kali上编译代码，并把编译好的可执行程序上传到靶机上，在靶机上运行。（但是可能架构不同？有需要交叉编译来在kali上编译出能在靶机上运行的程序）

思路二

之前在扫描dir的时候，发现有一个phpmyadmin页面和test页面，尝试查看这些页面： 直接访问http://192.168.50.10/test发现提示’file’ parameter is empty. Please provide file path in \file" parameter，因此猜测需要用post请求，用burp抓包改为post请求： 发现的确如此。 于是利用这个漏洞，尝试找出所有的用户名。 继续查看各个文件，发现：

c.php里面暴露了sql的密码，尝试用这个密码之后，登录phpmy页面，发现是phpmyadmin 然后在探索数据库的时候，发现了 一个新的用户信息，发现正是80端口的web应用的用户！

因此，可以回到前面思路一的方法，通过sql注入来继续操作。
