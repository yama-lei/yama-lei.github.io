文献阅读：A Comprehensive Review on Text Detection and Recognition in Scene Images

发表于2025-10-19|更新于2025-10-19|科研启蒙CVLearning
|总字数:587|阅读时长:2分钟|浏览量:

To capture a clear picture of the review, our plan is to divide the methods of text detection into regression [13], segmentation [14–16], and transform-based methods [17–19]. Similarly, recognition techniques are classified as transform and segmentation-based, encoder-decoder and attention-based, and connectionist temporary classification-based techniques.

Methods

Detection methods

Regression-based Text Detection Models 基于回归的文本检测模型，直接预测文本框的坐标：

  • CTPN：Connectionist Text Proposal Network 将文本看作是连续的小尺寸文本片段（anchors）序列，使用RNN连接这些片段来预测整个文本行。

Segmentation-based Text Detection models: 基于分隔的文本检测模型，将文本检测看作是一个像素级的分割问题，先生成文本区域的分割图，再通过后处理得到边界框

  • PSENet：a pixel-based method called Progressive Scale Expansion Network (PSENet) was introduced. 但是鲁棒性不是很强：However, PSENet needs to re-select the hyperparameters (minimum scale and number of segmentation results) for each dataset.
  • 太多了。。。一个方法可以举出N个模型 Transformer-based Text Detection Models: 利用Transformer的自注意力机制来捕捉全局上下文信息，从而更准确地进行文本检测。

Recognition Methods

目标是将检测到的文本区域图像转换成文本字符串。 基于CTC的方法 (Connectionist Temporal Classification): 适用于序列识别任务，它不需要对输入序列和输出标签做精确的对齐，非常适合识别长度不一的文本。

  • CRNN (Convolutional Recurrent Neural Network): 这是文本识别领域里程碑式的模型。它使用CNN提取图像特征，用RNN（通常是LSTM）处理序列上下文信息，最后用CTC层解码得到文本结果。 基于编码器-解码器和注意力机制的方法 (Encoder-Decoder & Attention-based): 借鉴自机器翻译。编码器（通常是CNN）将图像编码成特征向量，解码器（通常是RNN）基于注意力机制，一步步地“关注”图像的不同区域，并生成对应的字符。
  • RARE (Robust Text Recognizer with Automatic Rectification): 有一个空间变换网络（STN），可以校正不规则的文本，然后再进行识别。 基于Transformer的方法 (Transformer-based):  用Transformer完全替代RNN，利用自注意力机制并行地处理所有特征，捕捉长距离依赖关系。
    • NRTR (No-Recurrence Sequence-to-Sequence Model): 完全基于Transformer的结构，证明了在文本识别中可以不使用RNN。
