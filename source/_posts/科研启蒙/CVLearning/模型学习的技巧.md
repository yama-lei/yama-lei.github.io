## Optimizer: 优化器
### SGD（Stochastic gradient descent）
(Chinese Name: 随机梯度下降法)
The main idea of SGD can be explained by the following formula:
$$
W \leftarrow W - \eta \frac{\partial L}{\partial W}
$$
where $\eta$ stands for learning rate, which is ussally set to be predefined values like 0.001 or 0.01. 

```python
class SGD:
	def __init__(self, lr=0.01):
		self.lr=lr
	
	def update(self, params, grads):
		for key in params.keys():
			params[key]+=lr* grads[key]
```

SGD is easy to complement, but sucks at its efficiency. In an example of function $f(x,y)= \frac{1}{20}x^2+ y^2$
![image.png](https://yamapicgo.oss-cn-nanjing.aliyuncs.com/picgoImage/20250922223004.png) the gradient of the function is nearly parallel to the y axis, which means it can be hard to find the "best position" of the function

### Momentum  
Momentum is a physical concept which translates as 动量 in Chinese. The Mathematics explanation of Momentum goes like this:  
$$
v \leftarrow \alpha v - \eta \frac{\partial L}{\partial W} 
$$
$$
W \leftarrow W + v
$$
The only difference between SGD lies in the dynamic $v$ , which 'remenbers' the trendence of gradient.
$v$ represents the speed and the gradient presents the force. 


### AdaGrad
In the learning og Neaurl Network, the learning rate  $\eta$ is important. Learning rate decay proves to be effective which lower the learning rate gradually.

The AdaGrad gets its name from  "Adaptive" and "Gradience". The math logic of AdaGrad can be explained like this:
$$
h \leftarrow h + \frac{\partial L}{\partial W}\odot \frac{\partial L}{\partial W}
$$
$$
W \leftarrow W- \eta \frac{1}{\sqrt{h}} \frac{\partial L}{\partial W}
$$
which further shows how ada works: it acumulates the square sum of its gradients and lowers its learning rate gradully

## Batch Normalization
> 有待进一步地了解

Batch Normalization将神经网络中的值强制地正太分布化，调整各层的激活值分布使其拥有适当的广度，取得更好的学习效果。
-  可以使学习快速进行（可以增大学习率）。
- 不那么依赖初始值（对于初始值不用那么神经质）。 
- 抑制过拟合（降低Dropout等的必要性）
