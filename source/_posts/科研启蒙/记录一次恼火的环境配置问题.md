之前一直使用的是venv环境，但是python版本很旧（3.6.8），我想要使用更新的python版本（服务器只装了python2和python3.6.8），于是打算使用conda。
### 网络问题
尝试多次使用NJU mirror，来作为conda源，但是一直失败，后来发现发现：![image.png](https://yamapicgo.oss-cn-nanjing.aliyuncs.com/picgoImage/20251005161712.png)

原来如此......
无奈之下，我选择在校内另外一台服务器（我的HomeLab）上面运行squid，来作为网络代理，在GPU服务器上设置http_proxy和https_proxy来实现网络访问。
遇见了这些问题：
- conda里面无法识别到我的代理
- 在python代码里面无法识别我的代理
分别询问GPT，分别设置好环境，我将其所有配置写成了一个脚本：
```sh
(base) [vqa@localhost vqa]$ cat init-net.sh
export https_proxy="http://ip:3128"
export http_proxy="http://ip:3128"
export HTTP_PROXY="http://ip:3128"
export HTTPS_PROXY="http://ip:3128"
echo "成功设置命令行环境变量http/https代理"
conda config --set proxy_servers.http http://ip:3128
conda config --set proxy_servers.https http://ip:3128
echo "成功设置conda http/https代理"
echo "配置完成，试着curl一下外网"
(base) [vqa@localhost vqa]$ 
```

并且在python代码前面加上
```python
import os
os.environ['HTTP_PROXY'] = "http://172.26.8.119:3128"
os.environ['HTTPS_PROXY'] = "http://172.26.8.119:3128"
os.environ['http_proxy'] = "http://172.26.8.119:3128"
os.environ['https_proxy'] = "http://172.26.8.119:3128"
```

---
之后，开始了我快乐的conda install环节，期间发现，使用conda install会有很多的包出现出现冲突，许多包都因为我使用的是python3.13，而找不到对应的版本，后来尝试下载时指定channel为conda forge，解决了一部分问题，但是仍然在mlflow的使用的时候出现了严重的冲突和依赖地狱问题。

尝试重新开一个环境，之后，遇见了磁盘内存不足的报错，发现Home目录被我占满了......
于是尝试把cache和envs目录移动到我有权限的/project目录下，解决了问题。

但是又出现了新的问题，发现下载没有问题，但是在安装的时候一直卡主
尝试：
1. 耐心等待
2. 删除环境，重新下载
3. 在conda环境下使用pip install发现也会卡主
4. 在create env的时候加上一些附件包，也会卡主

最初怀疑网络问题和/project的io速度，后来一一排除。最后发现是/project的目录的NFS读写过慢，导致无法进行大规模的小文件读写IO，在测试这个的时候出现卡死的情况：
```sh
SMALL_CNT=10000
SMALL_SIZE=4    # KB per file
echo "=== 小文件创建测试: ${SMALL_CNT} 个 ${SMALL_SIZE}KB 文件 ===" | tee "$OUTDIR/05_smallfile.txt"
for TARGET in /home/vqa /project/vqa /work; do
  if [ -d "$TARGET" ]; then
    TESTDIR="$OUTDIR/small_${TARGET//\//_}"
    mkdir -p "$TESTDIR"
    echo "测试路径: $TARGET -> $TESTDIR" | tee -a "$OUTDIR/05_smallfile.txt"
    sync; sleep 1
    ( time python3 - <<PY  ) 2>&1 | tee -a "$OUTDIR/05_smallfile.txt"
import os,sys,time
d="$TESTDIR"
n=$SMALL_CNT
s=$SMALL_SIZE
t0=time.time()
for i in range(n):
    open(f"{d}/f{i:05d}.bin","wb").write(b'0'*(s*1024))
t1=time.time()
print("created",n,"files of",s,"KB in",round(t1-t0,3),"s")
PY
    rm -rf "$TESTDIR"
  else
    echo "$TARGET 不存在，跳过" | tee -a "$OUTDIR/05_smallfile.txt"
  fi
done
echo
```

后来实在是绝望了，把cache移到/tmp下，把/envs迁回home，但是问题还是没能解决。
