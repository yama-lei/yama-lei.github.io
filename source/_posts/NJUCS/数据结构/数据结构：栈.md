### 后缀表达式计算
**问题**
怎么计算`a b c d - * + e f ^ g / -`的值？
**思路**
从左向右顺序地扫描表达式，并用一个栈暂存扫描到的操作数或计算结果。
扫描中遇操作数则压栈；遇操作符则从栈中退出两个操作数，计算后将结果压入栈
最后计算结果在栈顶。

### 中缀转后缀

考虑一个中缀表达式： A + B*C -D，最终会变成：A B C *+D-

我们发现：

-   操作数的相对顺序不变
-   在运算顺序的限定下，存在FILO的现象
因此，可以这样操作：
读到operand的时候，直接输出；读到opertor的时候，存入栈中；读到“（”直接skip，读到“）”的时候弹出栈一个operator
`((A+B)-(C * D))`
`A B + C D * -` 
但是，这种解法需要我们先把括号给补齐，那么有没有一种算法，可以自由地处理各种形式的表达式呢？

我们可以选取这样的方法，将中缀表达式直接转换为后缀表达式：
1.  若为‘（’，入栈
2.  若为‘）’，则依次将栈中的运算符加入后缀表达式，直到出现‘（’，并从栈中删除‘（’
3.  若为‘+’，‘-’，‘*’，‘/’
-   栈空，入栈
-   栈顶元素为‘（’,入栈
-   高于栈顶元素优先级，入栈
-   否则，依次弹出栈顶运算符，直到一个优先级比它低的运算符或‘（’为止
简单来说：
-   如果是左括号，那么入栈，如果是右括号就一直出栈，直到左括号出栈
-   如果是操作符：
    -   如果当前的优先级比栈顶的优先级高，那么入栈
    -   否则出栈，直到遇见优先级更低的运算符或或者”（“

## 回溯算法
回溯算法(Backtracing)是一种通过**递归**和**试探**来解决问题的算法，核心思想是**穷举所有可能的解**，并在不满足条件时回退到上一步重新尝试。它常用于解决**组合问题**、**排列问题**、**子集问题**、**棋盘问题**等。
回溯算法的基本框架为：
```python
def backtrack(state, choices):
   if 满足解条件:
       保存解
       return
   for choice in choices:
       if 合法选择:
           做出选择
           backtrack(更新后的状态, 新的选择列表)
           撤销选择
```
其中“做出选择”和“撤销选择”可以使用栈的push和pop来模拟：

## 卡特兰数
**问题**
若入栈的顺序为1,2,3,4的话，输出所有可能的出栈的序列？
**思路**
使用回溯的思路：使用out，in数组分别代表出栈和准备入栈的数组
1. 如果out已经有n个数字了，直接输出
2. 否则，说明在栈里和in数组里面有数字，依次执行下面这两条
	1. 如果栈不为空，那么在这这里采取回溯的思路：
		- 尝试pop一个数字并且存入out中
		- **递归调用函数**
		- 把之前的数字push回栈中（**回溯**）
	2. 如果in数组不为空，那么在这里使用回溯的思路：
		- 尝试将一个数字push进栈中
		- **递归调用函数**
		- 把数字pop出栈，存回in数组（**回溯**）
**如果要求计数呢？**
如果只是计数的话，可以直接参考这个文章[卡特兰数 - OI Wiki](https://oi-wiki.org/math/combinatorics/catalan/)，使用递推公式来解决，不过需要注意，最好使用动态规划把之前算过的结构保存起来，减少复杂度。
## 单调栈
单调栈就是栈内元素具有单调性的栈，如果入栈的元素会破坏单调性，那么就把栈顶的元素退栈，直到允许当前元素入栈，即：
```cpp
/*push 'val' into the stack*/
while(stack is not empty && top<val){
	pop()
}
push(val)
```
