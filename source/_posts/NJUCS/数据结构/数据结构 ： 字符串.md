## **KMP算法**
在讨论问题之前，我们先定义一些符号：
匹配的字符串P，目标串为T，维护的当前索引为currentIndex
推荐阅读[[KMP 算法详解-labuladong的文章]]
**状态机解法**
把字符匹配看成是状态机的转移，

**书本的解法**
主要还是要关注书本的写法，因为书本上的解会是考试的重点！
KMP算法：目标串永远不后退，当发生失配的时候，让模式串回溯。
定义一个next数组，当失配的时候P串处于$P_j$位置时，下一次回溯到$P_{next(j)}$的位置和失配的那个字符进行比较，目标串不变，除非j=0（j=0说明是从开始就失配了，这种情况下应该让目标串前进一位）。
即：
```cpp
# i for t and j for p 
while(i<t.len&&j<p.len){
	if(j==-1||p[i]==p[j]){
		i++;j++;
		
	}else{
		//如果失配就回溯
		j=next[j];
	}
}
```

构造Next数组：
```cpp
int k=-1;
int j=0;
next[j]=k;
while(j<p.len){
	if(k==-1||p[j]==p[next]){
		j++;k++;next[j]=k;
	}else{
		k=next[k];
	}
}
```

### Next数组的优化
在面对aaaaa之类的P的时候，next数组显得有些无能为力。这个时候就需要：
方法一：从next数组开始构建
```cpp
nextval[0]=-1;
for(int i=1;i<lenP;i++){
if(p[next[i]]==p[i]){
		nextval[i]=nextval[next[i]];
	}else{
		nextval[i]=next[i];
	}
}
```
方法二：直接从0开始一步构建
```cpp
int k=-1;
int j=0;
next[j]=k;
while(j<p.len-1){
	if(k==-1||p[j]=p[next]){
		j++;k++;
		if(p[j]==p[k]){
			next[j]=next[k];
		}else{
			next[j]==k;
		}
	}else{
	k=next[k];
	}
}
```




### 如何找到所有的匹配情况？
在找到一个完整的匹配的时候，如何紧接着找下一个匹配呢？

T: abcabcabc
P: abcabc
容易得到P的next数组为 -1 0 0 0 1 2
在匹配的过程中，会出现：
```text
       |
T abcabcabc
P abcabc
```
当匹配到c的时候，发现`T[i]==P[j]`，因此i++;j++;之后，满足条件`j==lenP`,成功匹配一次，进行下一次匹配，此时最佳的选择是重新给j复制为`next[j]`，让P串回溯，进行下一次匹配的查找，因为`next[j]`的含义即为前整个串的最长公共前后缀长度，回到`next[lenP]`这个位置能够最大程度地减少匹配的成本。
